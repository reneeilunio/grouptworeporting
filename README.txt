EUROPA — Cinematic & Realistic Website
Files: index.html, style.css, script.js.
Open index.html in a browser. Internet is required for remote photography and fonts.

GitHub Pages publishing:
1. Create a GitHub repository.
2. Upload the three files to the repository root.
3. Go to Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.

Notes:
- Ask the Artist currently uses prepared demo responses, not a live AI model.
- Ambient sound is not implemented yet; its label is marked as coming soon.
- For live AI, use a secure backend/serverless function and keep API keys out of script.js.
- Images are remotely loaded from Unsplash.
- Review all destination and artwork references against your instructor's slides before presenting.
